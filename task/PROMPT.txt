写 caskpatch 复核隔离档案柜的磁盘索引修复。输入是两个合成清单，每个清单描述分块树。块按内容摘要去重但槽位按稳定 ID 区分，分区有写权限和固定容量。引用到同一条索引的档案版本必须对该索引做原子替换。过程可在写入候选块、更新根引用、释放旧块之间任意阶段断电，断电后只能看见完整旧版或完整新版，除非原日志已经显式记录旧版损坏。保护等级随引用链传播，低保护域不能暂存从高保护域传来的块；更强分区可同时存不同原材料的同摘要块，但不同保护标签不能互相洗掉。
做 check CASE TRACE，重算每一步可见根及唯一块重复计数，输出最早出现的不安全断点、引用链和空间峰值。做 arrange CASE，以最长 16 个分块切换为输入选择顺序和暂存目标，使每个断点均可恢复并满足所有保留快照。先最小化附加空间峰值，再最少跨域操作，最后比较动作 ID。另做 verify 对输入清单重新复算，给只在提交后看起来合理却在中途暴露错误摘要的反例；还要有两个原子提交共享旧块、提前释放导致回滚失败的例子。测试应在至少三个阶段杀掉子进程，再重开自己创建的本地数据库。
从空仓库实现，使用 Windows 普通 CPU 和 Python 3.12 标准库，全部离线。交付 UTF-8 JSON CLI、明确的输入格式、README、合成夹具及 unittest。
